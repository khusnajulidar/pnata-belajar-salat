# P'Nata — Yuk, Belajar Salat!

Worksheet anak 10 halaman untuk mengenal salat sesuai Sunnah. Target pembaca: anak kelas 1–2 SD.

## Status proyek
- Halaman 1 — Sampul: selesai dan disetujui.
- Halaman 2 — Ayo Kenali 5 Waktu Salat!: selesai dan disetujui.
- Halaman 3 — Sudah Siap untuk Salat?: konsep dan ilustrasi pernah dibuat; final masih perlu diperiksa dan disetujui.
- Halaman 4 — Kenali Urutan Gerakan Salat!: konsep disetujui; ilustrasi final belum dibuat.
- Halaman 5–10: belum ditetapkan secara final.
