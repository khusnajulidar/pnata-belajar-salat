# Panduan Proyek — P'Nata: Yuk, Belajar Salat!

## 1. Identitas dan tujuan
- Produk: worksheet anak 10 halaman.
- Judul: **YUK, BELAJAR SALAT!**
- Subjudul: **Petualangan Mengenal Salat Sesuai Sunnah**
- Target: anak kelas 1–2 SD.
- Penggunaan: produk digital untuk dijual melalui Lynk.

## 2. Prioritas utama: ketepatan agama
1. Materi harus selaras dengan Al-Qur'an dan Sunnah yang sahih, dengan rujukan yang dapat diperiksa.
2. Jangan mengarang teks Arab, harakat, transliterasi, terjemahan, dalil, atau ketentuan fikih.
3. Jika ada perbedaan pendapat ulama yang berpengaruh pada materi, verifikasi dan jelaskan secara proporsional; jangan menyatakan satu rincian sebagai satu-satunya ketentuan tanpa dasar.
4. Bahasa anak boleh disederhanakan, tetapi makna dan ketentuan agama tidak boleh berubah.
5. Bedakan hal wajib, sunnah, dan hal yang merupakan penyederhanaan pedagogis.
6. Periksa kembali teks Arab dan sumber sebelum materi masuk ke desain final.

## 3. Standar visual
- Hindari gambar makhluk bernyawa (manusia dan hewan) jika tidak diperlukan.
- Jika karakter manusia diperlukan: tanpa mata dan tanpa alis; tidak menampilkan leher; karakter anak laki-laki memakai gamis/thobe panjang dan menutup aurat.
- Gaya: ilustrasi kartun 3D, ceria, ramah anak, profesional.
- Warna cerah dan harmonis; pencahayaan, proporsi karakter, panel, tipografi, dan jarak harus konsisten.
- Jangan membuat halaman terlalu padat, teks terpotong, atau huruf terlalu kecil.
- Format halaman: A4 portrait. Target keluaran terdahulu 1055 × 1491 px, PNG berkualitas tinggi.
- Jangan menambahkan label “P'Nata Education” di kanan atas.
- Jangan menambahkan label nomor halaman yang tidak disetujui. Halaman 3 tidak memakai “HALAMAN 3”; konsep halaman 4 juga tanpa label nomor halaman.

## 4. Logo — aturan mutlak
- Gunakan aset logo asli sebagai layer terpisah.
- Jangan menggambar ulang, membuat tiruan, mengganti dengan teks, mengubah bentuk, warna, atau komposisi ikon.
- Posisi logo: kiri atas.
- Nama aset yang pernah disebut: `PNata_Ikon_HQ_4x.png`.
- Jika file belum tersedia di repository, minta pengguna mengunggahnya satu kali atau menambahkannya ke repository. Jangan membuat logo pengganti.

## 5. Alur kerja setiap halaman
1. Susun materi dan aktivitas.
2. Verifikasi ketepatan agama dan sumbernya.
3. Tentukan tata letak dan kebutuhan ilustrasi.
4. Tampilkan konsep kepada pengguna.
5. Tunggu persetujuan konsep.
6. Buat ilustrasi final.
7. Tempatkan logo asli sebagai aset terpisah.
8. Periksa teks, ejaan, Arab, harakat, komposisi, margin, resolusi, dan konsistensi.
9. Simpan file sumber/hasil dan catat perubahan.
10. Tunggu penerimaan pengguna sebelum melanjutkan ke halaman berikutnya.

Jangan meminta persetujuan ulang untuk konsep yang sudah disetujui. Jangan menyatakan file selesai jika belum benar-benar dibuat dan diperiksa. Jika alat atau batas penggunaan menghambat pekerjaan, jelaskan apa adanya.

## 6. Status dan keputusan halaman

### Halaman 1 — Sampul
- Judul: “YUK, BELAJAR SALAT!”
- Subjudul: “Petualangan Mengenal Salat Sesuai Sunnah”.
- Visual yang pernah dirancang: masjid, taman/langit, anak, buku, dan sajadah.
- Karakter sesuai standar tanpa mata/alis dan tanpa leher.
- Status: selesai dan disetujui.
- File terdahulu disebut: `Halaman_1_Cover.png` (keberadaan file di repo belum diverifikasi).

### Halaman 2 — Ayo Kenali 5 Waktu Salat!
- Pengantar: “Yuk, kenali nama salat wajib dan jumlah rakaatnya!”
- Subuh 2 rakaat; Zuhur 4; Asar 4; Magrib 3; Isya 4. Total 17 rakaat.
- Lingkup: salat fardu bagi orang mukim/tidak sedang safar; bukan salat sunnah dan bukan pembahasan qasar.
- Visual suasana: fajar, siang, sore, matahari terbenam, malam.
- Aktivitas: “PASANGKAN!” (nama salat dan jumlah rakaat); “LENGKAPI JAWABANNYA!” (Subuh, Magrib, Isya).
- Tidak ada tulisan “P'Nata Education” di kanan atas; logo asli di kiri atas.
- Status: selesai dan disetujui.
- File terdahulu disebut: `Halaman_2_Ayo_Kenali_5_Waktu_Salat.png` (keberadaan file di repo belum diverifikasi).

### Halaman 3 — Sudah Siap untuk Salat?
- Pengantar: “Yuk, periksa persiapan salatmu!”
- Enam pokok:
  1. Bersuci dari hadas: wudu untuk hadas kecil; mandi wajib untuk hadas besar; tayamum ketika syaratnya terpenuhi.
  2. Bersih dari najis: badan, pakaian, dan tempat salat.
  3. Menutup aurat ketika salat.
  4. Telah masuk waktu salat.
  5. Menghadap kiblat.
  6. Berniat dalam hati; jangan mengajarkan lafaz niat tertentu sebagai syarat wajib.
- Aktivitas: “BERI TANDA CENTANG!” dan “TEMUKAN KESALAHANNYA!”
- Rujukan yang pernah dipakai: QS Al-Ma'idah 5:6; QS An-Nisa 4:103; Sahih Muslim 224a.
- Status: ilustrasi pernah dinyatakan selesai, tetapi final belum disetujui pengguna. Periksa ulang apakah misi kedua benar-benar menampilkan kesalahan yang dimaksud.
- File terdahulu disebut: `Halaman_3_Sudah_Siap_Untuk_Salat.png` (keberadaan file di repo belum diverifikasi).

### Halaman 4 — Kenali Urutan Gerakan Salat!
- Pengantar: “Yuk, belajar gerakan salat dari awal sampai akhir!”
- Tujuh tahap yang disepakati untuk menjelaskan satu rakaat:
  1. Berdiri dan takbiratul ihram.
  2. Berdiri membaca bacaan salat.
  3. Rukuk.
  4. Iktidal.
  5. Sujud pertama.
  6. Duduk di antara dua sujud.
  7. Sujud kedua.
- Teks takbir: اللهُ أَكْبَرُ — wajib diperiksa kembali penulisan Arab/harakat saat produksi.
- Sujud: jelaskan tujuh anggota sujud dengan redaksi yang akurat dan sesuai dalil.
- Catatan fikih penting: tujuh tahap ini menggambarkan satu rakaat, bukan keseluruhan salat. Setelah sujud kedua, berdiri ke rakaat berikutnya jika belum rakaat terakhir; jika rakaat terakhir, duduk untuk tasyahud akhir. Pembahasan tasyahud lebih rinci direncanakan pada halaman 8.
- Aktivitas: “MISI 1 — SUSUN URUTANNYA!” (urutkan kartu gerakan 1–7); “MISI 2 — COCOKKAN GERAKANNYA!” (cocokkan nama gerakan dan gambar).
- Rujukan yang pernah disebut: Sahih al-Bukhari 631; Sahih Muslim 471a; Sahih Muslim 497b. Verifikasi nomor/teks dan kesesuaian sebelum publikasi.
- Status: konsep disetujui pengguna; ilustrasi final belum dibuat. Lanjutkan membuat ilustrasi final tanpa meminta persetujuan konsep lagi.
- Tidak ada label nomor halaman; logo asli di kiri atas; tanpa “P'Nata Education”.

### Halaman 5–8
- Direncanakan sebagai kelanjutan gerakan dan bacaan salat.
- Halaman 8 direncanakan membahas duduk/tasyahud secara lebih rinci.
- Judul, isi, dalil, dan aktivitas belum disepakati. Jangan menganggap rancangan baru sebagai keputusan terdahulu.

### Halaman 9–10
- Termasuk rencana total 10 halaman.
- Topik dan isi belum disepakati. Jangan menetapkan topik seolah sudah disetujui.

- Repository GitHub ini menjadi sumber utama dokumen proyek, aset, dan riwayat revisi.
- Simpan file final halaman di `exports/final/`, pratinjau di `exports/preview/`, dan aset sumber pada folder terkait.
- Gunakan nama file yang deskriptif dan konsisten, misalnya `page-04-gerakan-salat-v01.png`.
- Setiap perubahan penting dicatat di `CHANGELOG.md`.
- Jangan mengasumsikan file yang disebut di percakapan sudah ada di repository; cek isi repository terlebih dahulu.
- Repository saat ini Public sesuai keputusan pengguna. Jangan menyimpan kredensial, data pribadi, atau materi berhak cipta tanpa izin.
